# DOM Sketchbook

### A browser-based playground for practicing JavaScript and DOM manipulation

</div>

---

## About the project

DOM Sketchbook is a collection of small frontend experiments created to strengthen my practical understanding of JavaScript and the browser DOM.

Instead of learning concepts only through isolated examples, the project explores how JavaScript can respond to user actions, update page content, modify styles, and preserve data inside the browser.

## What it explores

■ DOM selection and manipulation <br>
■ Event listeners and user interactions  <br>
■ Dynamic content updates  <br>
■ Adding and removing CSS classes  <br>
■ Working with forms and user input  <br>
■ Creating interactive interface behaviour <br>
■ Storing browser data with Local Storage  <br>
■ Connecting HTML, CSS, and JavaScript  <br>

## Built with

| Technology        | Purpose                                    |
| ----------------- | ------------------------------------------ |
| **HTML5**         | Page structure and interface elements      |
| **CSS3**          | Layout, styling, and visual feedback       |
| **JavaScript**    | DOM manipulation and interactive behaviour |
| **Local Storage** | Browser-based data persistence             |

## JavaScript concepts used

* Variables and functions
* Arrays and objects
* Conditional logic
* DOM selectors
* Event handling
* Class and content manipulation
* Array methods
* Form input handling
* Local Storage
* Dynamic interface updates

## Getting started

Clone the repository:

```bash
git clone https://github.com/andrejbuilds/dom-sketchbook.git
```

Open the project directory:

```bash
cd dom-sketchbook
```

Open `index.html` directly in your browser or run the project using a local development extension such as Live Server.

## Purpose of the project

DOM Sketchbook was created as a practical learning space where I can experiment with browser-based JavaScript without every exercise needing to become a complete application.

It allows me to test individual ideas, understand how they work, and gradually improve my frontend development skills through hands-on practice.
